# Social Media Analysis Using Python

## Project Overview

This project analyzes social media data to understand user engagement, content performance, audience behavior, and sentiment patterns.

The analysis was performed using Python and different data analysis and visualization techniques.

## Dataset

The dataset contains **5,000 social media records** with information about:

* User demographics
* Post type and category
* Likes, comments, and shares
* Watch time and impressions
* Follower count
* Engagement rate
* Sentiment
* Device type
* Verification status
* Hashtags
* Posting date and time

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Jupyter Notebook / Google Colab

## Data Cleaning & Wrangling

* Handled missing values
* Checked duplicate records
* Converted date/time columns
* Standardized categorical values
* Checked data types
* Performed outlier analysis

* Created `hashtags_count`
* Performed groupby analysis
* Used merge/join operations

## Key Insights

* Video posts had the highest average engagement rate (**1.122**).
* Food content performed best with an average engagement rate of **1.359**.
* Brazil recorded the highest average engagement rate (**1.541**).
* The **46+ age group** had the highest average engagement rate (**1.079**).
* Verified accounts showed higher engagement (**1.05**) than unverified accounts (**0.95**).
* Mobile users had the highest average watch time (**4,087.83 seconds**).
* Negative sentiment posts had the highest engagement rate (**1.038**).
* The dataset did not have enough time variation to determine the best time of day for impressions.
* These patterns can help identify high-performing content and support future content planning.
